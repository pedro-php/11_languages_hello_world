# Hello World in 11 Languages

## Instructions

### Compiled Languages

#### 1. C 
Compile: `gcc helloworld.c -o helloworld`

Run: `./helloworld`

#### 2. C++
Compile: `g++  -o helloworld_cpp helloworld.cpp`

Run: `./helloworld_cpp`

#### 3. Java
Compile: `javac helloworld.java`

Run: `./helloworld`

#### 4. Go

Run: `go run helloworld.go`

### Interpreted Languages

#### 5. Python

Run: `python3 helloworld.py`

#### 6. Node

Run: `node helloworld.js`

#### 7. Ruby

Run: `ruby helloworld.rb`

#### 8. PHP

Run: `php helloworld.php`

#### 9. Perl

Run: `perl helloworld.pl`

#### 10. Shell Script

Run: `sh helloworld.sh"`
